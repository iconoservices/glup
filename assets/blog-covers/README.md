# Portadas de la Revista

Dejá acá una imagen llamada `<slug>.jpg` (o .png/.webp) para que se use como
portada de esa nota en vez de la generada automáticamente.

Ejemplo: `assets/blog-covers/primera-fiesta-swinger.jpg`

Se recorta sola a 1200x675. Después corré `npm run gen:covers` y commiteá
el `public/blog/cover-<slug>.jpg` resultante.
